# درع

موقع ذكاء اصطناعي مستقل لشرح الأمن السيبراني وكتابة الكود. يشتغل بمزودات خارجية (مفاتيحك أنت)، ما له علاقة بـ Claude أو Anthropic، ويشتغل من أي متصفح بدون ما تفتحه داخل تطبيق معيّن.

## 1) التشغيل على جهازك

```bash
pip install -r requirements.txt
python server.py setup      # يطلع لك باسورد طويل. انسخه الحين، ما يظهر مرة ثانية
python server.py            # افتح http://127.0.0.1:8000
```

ادخل بالباسورد، افتح **الإعدادات**، والصق مفتاح نموذج واحد على الأقل، واضغط **اختبار**.

مفاتيح مجانية: Gemini من Google AI Studio، وGroq، وOpenRouter (موديلات `:free`)، وMistral. أو Ollama محليًا بدون مفتاح. تقدر تضيف أي مزود ثاني يدعم صيغة OpenAI (DeepSeek، Together، Cerebras...) من نفس شاشة الإعدادات.

## 2) تثبيته كتطبيق

افتح الرابط من المتصفح:
- أندرويد/كروم: القائمة ثم **تثبيت التطبيق**.
- آيفون/سفاري: زر المشاركة ثم **إضافة إلى الشاشة الرئيسية**.
- الكمبيوتر (كروم/إيدج): أيقونة التثبيت في شريط العنوان.

## 3) رابط تفتحه من أي مكان

### الأسرع: نفق Cloudflare (مجاني، من جهازك)
ثبّت `cloudflared`، شغّل السيرفر، وبعده النفق في نافذة ثانية:

```bash
HUB_BEHIND_PROXY=1 python server.py
cloudflared tunnel --url http://localhost:8000
```

يطلع لك رابط `https://....trycloudflare.com` يشتغل ما دام جهازك شغّال، ويتغيّر كل مرة تعيد التشغيل.

### رابط ثابت: استضافة (مثل Render)
1. ارفع المجلد على GitHub (`.gitignore` يمنع رفع المفاتيح).
2. في Render: **New → Web Service**، اختر الريبو، النوع **Docker**، الخطة المجانية.
3. في **Environment** أضف:
   - `HUB_ADMIN_SALT` و`HUB_ADMIN_HASH` (من مخرجات `setup`)
   - `HUB_KEY_GEMINI` و`HUB_KEY_GROQ` وهكذا لكل مزود (الاسم بعد `HUB_KEY_` هو اسم المزود بحروف كبيرة)
4. بعد النشر تاخذ رابط ثابت `https://اسمك.onrender.com` تفتحه من أي جهاز.

ملاحظة: الاستضافة المجانية تنام بعد خمول (أول فتح بطيء)، والتغييرات اللي تسويها من الإعدادات تضيع عند إعادة التشغيل، فخلّي المفاتيح في متغيرات البيئة مو بس في الواجهة.

## الأمان والحدود

- الموقع كامل خلف باسورد واحد (هاش scrypt فقط، والمحاولات الغلط تتحظر 15 دقيقة).
- المفاتيح ما ترجع للمتصفح أبدًا.
- الذكاء اللي يجاوبك هو أي موديل تحط مفتاحه (مو Claude)، فهو يشرح الأمن السيبراني من الجانب الدفاعي والتعليمي ويكتب أي كود عادي تطلبه، لكنه برضو له سياسات أمان خاصة فيه (كل مزود له سياسته)، فما تتوقع منه يكتب برامج ضارة فعلية حتى لو غيرت الصياغة.
- تغيير الباسورد: `python server.py setup` من جديد.
